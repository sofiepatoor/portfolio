# Sofie's personal website

Hi there, welcome! This website had been hibernating for a while until I ~~recently~~ rebooted it at the beginning of 2026. It was supposed to start out as just a blog about (front-end) development and a place to showcase some dev projects, but things have turned around!

Now, I want my website to be a place where I can express myself. This means I will still post about dev-related things, but it will grow to be much more than that :)
